# Broccoli Launcher

A small, non-commercial hobby launcher for Minecraft: Java Edition, built with Electron.

## What it does
- Downloads Minecraft 1.21.11 from Mojang's official servers and installs Fabric.
- Starts the game with "Broccoli Client", a hobby Fabric mod (HUD modules such as FPS and coordinates).
- Planned: sign players in with their own Microsoft account using the device code flow. Login tokens will only be stored on the player's own computer.

## Status
Work in progress. This is a personal learning project.

## Privacy
The launcher does not collect or send any data to the developer.
